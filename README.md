# Keel Data Actor examples

Example code, real sample output and pricing for the Keel Data Actors on the Apify Store. Each folder has a README with
Python and JavaScript examples and an `examples/` directory. Keel Data built these tools.

| Actor | What it does | Store |
|---|---|---|
| [ats-job-board-scraper](ats-job-board-scraper/) | Open jobs from any Greenhouse, Lever or Ashby board as flat JSON, with monitor mode | https://apify.com/loamy_barista/ats-job-board-scraper |

More folders are added one per day.
